# 🎮 Battle Tanks — 坦克大战

一款用原生 HTML5 Canvas 实现的经典坦克大战（Battle City 风格）小游戏，单文件、零依赖，打开即玩。

## 玩法

- **目标**：消灭每一关的所有敌方坦克，同时保护底部的「老鹰基地」。基地被击中即游戏结束。
- **操作**：`WASD` / 方向键移动，`空格` / `J` 射击，`P` 暂停，`M` 静音。
- **支持触屏**：在手机 / 平板上会自动显示虚拟方向键与开火按钮。

## 特性

- 4 种敌方坦克：普通（灰）、快速（红）、火力（绿，炮弹可击穿砖墙）、装甲（蓝，3 点生命）
- 可破坏的砖墙、不可破坏的钢墙、可通行子弹的水面、能隐藏坦克的草丛
- 关卡递进：敌人数量与速度逐关提升，共 5 关通关
- 计分、生命、敌人剩余数量 HUD
- 爆炸粒子特效 + Web Audio 音效
- 支持手机触屏操作

## 快速开始

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

也可以起一个本地静态服务器：

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 在线试玩

部署到 GitHub Pages 后，访问 `https://<你的用户名>.github.io/tank-battle/` 即可游玩。
